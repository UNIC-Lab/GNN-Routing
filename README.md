# GNN-Routing
This is the code for "Graph Neural Network-Based Multicast Routing for On-Demand Streaming Services in 6G Networks" accepted by IEEE TMC.

- Developed with Python 3.10
- requirement:
  - torch==2.7.1+cu128
  - torch-geometric==2.7.0
- Please cite this paper in your work when using this code repository：\
  X. Wang, Z. Wang, N. Cheng, W. Xu, W. Quan, and X. Shen, “Graph neural network-based multicast routing for on-demand streaming services in 6g networks,” IEEE Trans. Mob. Comput., pp. 1–13, 2025.
